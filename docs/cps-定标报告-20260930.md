## 三、定标结论

### 结论一：CPS 行动层阈值定标为 **5.0（CJK 译文）**

- 依据：≈档案 p95（4.77）+5% 裕度；触发率 3.87%，配合**每片行动条目截断上限 20**（沿 audio_detect_max_candidates 防洪水先例，超限在报告注明），实际入导读条目 ≤20 条/片，可人工复核。
- 与观测层的关系：观测层（8.0/20.0×1.15）回答"是否超出通用可读性底线"，**保持不动**；行动层（5.0）回答"是否显著快于本语料定标的典型节奏、值得定点重看"。两层问题不同、并存不冲突；行动层比观测层更严是本语料（密集短句字幕风格）的定标结果。
- 预估区间（roadmap"4-5 区间"）落 5.0 上缘：4.0~4.5 触发率 7~13% 属噪声区间，不采纳。
- "场景感知容差"落地口径：**v1 不做自动场景识别**（规则级场景分类不可靠、无训练数据），落地为行动阈值/上限经 `config/user_settings.json` 分层可调（`cps_action_enabled` / `cps_action_threshold` / `cps_action_max_per_film`），按素材调整的指引写入手册。
- 降级说明：本定标基于中文译文（CJK 判定成立）语料；非 CJK 条目沿用观测层口径（20×1.15）不进入行动层，直至相应语料定标。

### 结论二：时间轴间隙**不行动化**（数据否决），维持观测层

批次 E 实测：相邻条目间隙 >5s 者占条目 10%~20%（163~346 条/片），>8s 仍达 72~207 条/片——大间隙是此类素材的结构性节奏（场景转场/音乐段/无对白段），不是缺陷信号。纯时间轴间隙的行动化将产生每片数百条噪声。对"漏翻段落"的行动语义已由音频能量粗筛（`suspected_missed_speech`，2.0.0 已落）按能量证据承担。间隙观测（>5s 提示）保留现状。

## 四、行动化实施口径（供 2.0.1 第二件执行）

1. 新导读条目类别 `cps_too_fast`（仅 CJK 译文条目参与；`current_text` 取终稿文本，可定点重翻）；
2. `action_retranslate._CATEGORY_HINTS` 增对应处理要点：精简措辞压缩字数、保留原意，使语速回到可读区间（时长不可改，只能减字）；
3. 三参数进 `TUNABLE_FIELD_TYPES`（沿 audio_detect 三步模式）：`cps_action_enabled=True` / `cps_action_threshold=5.0` / `cps_action_max_per_film=20`，不加 CLI 参数；
4. 章节渲染注明行动层口径来源（本报告）与截断上限；观测章节免责句保持；
5. 回归测试：触发/不触发/截断/参数关闭/非 CJK 不参与五类；全量基线只增不减。

## 五、残留风险跟踪

- 增量语料到位后复核 5.0 定标（重点：非 JAV 通用语料的分布是否左移——通用模板语料节奏或更稀疏，届时按语域分档再议）；
- 行动条目与 `single_line_too_long` 同条目双类触发的去重呈现（实施时确认导读组装行为并钉测试）；
- 阈值参数化后 owner 实测反馈回填缺省值。
