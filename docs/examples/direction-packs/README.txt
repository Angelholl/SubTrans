方向角色示例卡（zh→en / en→zh）—— 非缺省翻译方向专用
========================================================

这是什么
--------
SubTransJAV 缺省自带日→中两张角色卡（净语翻译/审校抛光）。切其它翻译
方向时，校验要求为全部启用阶段显式指定配套模板卡——本包提供中→英、
英→中两个方向的自制示例卡，可直接使用，也可在此基础上按片源调优。

怎么用（GUI）
--------
1. 高级参数页「翻译方向」：源语言/目标语言切到对应方向；
2. 「阶段A 指令卡」填本包净语翻译卡完整路径，「阶段B 指令卡」填审校
   抛光卡完整路径；
3. 回字幕翻译页选文件开跑；产物按方向命名（如 *_final_en.srt）。

怎么用（CLI）
--------
subtransjav-refine -i 输入.srt --source-lang zh --target-lang en ^
  --s1-instructions 角色-净语翻译.zh2en.txt ^
  --s3-instructions 角色-审校抛光.zh2en.txt

说明
----
- 卡内【语法提示】相关条款：管线会在部分行注入分词/语法辅助段（zh 源
  需可选组件 [zh]，即 pip install -e ".[zh]"；未安装自动跳过），卡里
  的防回显条款防止辅助段混入终稿，请保留。
- 缺省日→中方向不要填这两张卡：目录自动查找的两张包内卡（日→中特调）
  仍按原逻辑生效。
- 本包与 docs/examples/jav-domain/ 领域包相互独立：领域包调"内容风格"，
  方向卡定"语言对"，可按需同时使用（领域包替换缺省日→中卡时仅影响
  缺省方向）。
