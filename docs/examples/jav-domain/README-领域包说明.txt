【领域示例包 — JAV 调校版（docs/examples/jav-domain/）】

本目录是"领域包"的一个完整示例：面向 JAV（成人影片）字幕场景的
角色卡与配套规则 YAML，成对打包，供领域用户参考或整包导入。

────────────────────────────────────────
一、文件清单（模板/规则成对提供）
────────────────────────────────────────
角色卡（2 张）：
- 角色-净语翻译.txt    阶段A：净语清洗 + 日译中翻译（JAV 场景调校版，
                        含成人语境敏感词分级对照表、イク系高潮语境译法等）
- 角色-审校抛光.txt    阶段B：翻译审核 + 中文抛光（JAV 场景调校版）

规则 YAML（4 份，与角色卡配套设计）：
- translation_rules.yaml        提示词加固段的数据源（整文件替换语义）
- source_hallucination.yaml     闸门0 源侧幻觉检测规则（整文件替换语义）
- hallucination_patterns.yaml   幻觉/噪音删除模式（整文件替换语义）
- hardened_phrases.yaml         HARDENED 豁免词表（亲密/成人场景保护词）

────────────────────────────────────────
二、导入方式与语义（重要）
────────────────────────────────────────
导入 = 整包替换语义：
- 角色卡 → 复制到数据根 config/templates/（同名覆盖，优先于包内通用模板）；
- 规则 YAML → 复制到规则覆盖目录（config/rules/，存在即整文件替换包内默认，
  不做深层合并）。
- 须成对导入：模板措辞（如敏感词分级表、イク系条款）与词库保护范围
  （hardened 豁免词）是配套设计的，只换其中一半会导致保护缺口或规则空转。

回退到通用模板：删除数据根对应覆盖文件即可——程序按四级回落链
（显式配置 → 数据根 config/templates → 包内 defaults/templates → 报错）
自动回到随程序自带的通用模板与通用规则层。

────────────────────────────────────────
三、适用与免责
────────────────────────────────────────
- 本示例包仅面向拥有合法字幕翻译场景的成年用户，属于可选内容，不随
  通用模板默认生效；
- 动漫 / GAL 等其他领域请勿直接套用本包，应参考其结构另行定制
  （通用情绪词部分可沿用，见 docs/领域包-hardened-审计-20260930.md）。
