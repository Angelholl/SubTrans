# 真机走查清单-265测试版（setup-2.6.5.dev0.exe）

> 依据：D2026-1004-01（2.6.5 词典链与 UX 修复版）。构建=main f31be71，CI 已过 jieba 双层冒烟断言（dict.txt 落位+真跑分词）。
> 本清单为测试包专用紧凑版；正式发版走查以批4 新编《真机走查清单-265》为准。

## A 发版门②（核心，决定能否正式发版）

1. **词典下载端到端（关代理）**：关闭系统代理（或 v2rayN 退出/分流直连）→ ASR 与词典页 → 日语（sudachi）→ 下载 → 应成功落位，状态卡变 3/4 可用。
2. **词典下载（开代理复测）**：恢复代理 → 点「重新下载」→ 修复后应自动直连重试成功；若仍失败，应见红色人话行+「技术详情」展开（记录展开内容截图反馈，诊断字段可直接定位根因）。

## B 六项修复逐项

3. **安装器图标**：setup-2.6.5.dev0.exe 文件图标=应用图标（非 Inno 默认）。
4. **中文词典渠道**：词典管理页 → 中文（jieba）chip 实心点、pill「可用」；系统状态卡 2/4 可用（英文内置+jieba）；翻译设置开启中文分词提示不再提示不可用。
5. **状态卡两行式**：右栏底部路径完整显示不截断（长路径在分隔符处折行），统计值（N 条·命中 N 次/N/4 可用/N 张）在各行右侧。
6. **引擎页整合**：API 与模型选择页无「阶段A/阶段B/兜底」子 TAB，三段纵向一页（组头：阶段A·净语+翻译／阶段B·审校+抛光／兜底与容错），控件齐全。
7. **词典页入口收敛**：无顶部「去下载日语词典」引导条；四 chip 状态行（日语·中文·英文·完整版，完整版悬停提示与日语二选一）；详情区单操作行=下载源（仅官方│仅镜像）+右侧主下载键；切到中文词典不再出现误导的下载提示条。
8. **下载失败信息**（若 A2 触发失败）：一行红色人话+「技术详情」展开（预期/实际字节、Content-Encoding、响应前缀、来源 URL+复制、代理/直连、尝试次数）。

## C 回归抽查

9. **ASS/VTT 导入**：拖入 .ass/.vtt 片源字幕可进管线；如源文件有坏行，警告含「第 N 行「原文」」明细。
10. **常规链路**：按日常习惯跑一段净语翻译全流程（TM 搜索/校对页/质量报告随手抽查），确认无新增异常。

## 反馈方式

- 每项 PASS/FAIL+截图（FAIL 必附）；A2 失败时「技术详情」展开截图最重要。
