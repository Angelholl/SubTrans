## 0. 事实校正（实现者务必先看，避免改错页/改错元素）

1. **该区不在引擎页**：卡片正文沿用 owner 口述称「引擎页 AI 分析参数区」，但 DOM 实况是 `#refineAiAnalyzeSection`（`index.html:698`）位于 **`tab-guide`「质量与建议」页**（该页 :631 起，下一页 `tab-advanced` 起于 :772）。落地一律以 DOM 为准，勿按「引擎页」找元素。
2. **owner 指的是「生效行」，不是三件套状态行**：截图里下拉框下方那行 `分析模型：独立配置 — lmstudio / …` 由 `#refineAiPrivacy`（`index.html:761`）承载（`app.js:7099-7111 aiRefreshEffective` 写入）；而 `.model-trio` 内的 `.ai-model-status`（`index.html:753`）是刷新/测试的临时回显。二者同名不同物，**勿动错对象**。
3. 该区 `.ai-config-row` 全宽于 `.main` 内容区（`tab-guide` 未挂 `.page-narrow`，全仓 `page-narrow` 零引用），因此**框宽随窗口剧烈变化**——这正是「跨片窗口框宽远超内容」的放大器。

## 2. 跨片窗口下拉宽度收敛

### 2.1 `--w-*` 族可复用性审计（卡片点名项）

`.form-select.compact` 实测口径：字号 `--font-xs`=12px、左内边距 10px、右内边距 `var(--space-6)`=32px（自定义箭头 `style.css:1010-1017`）、边框 2px。
最长选项 `全部（永久）`（`app.js:884`）= 6 全角字 ≈72px → **内容实需 ≈116px**。

| 候选 token | 值 | 判定 |
| --- | --- | --- |
| `--w-concurrency` | 60px | 差 56px，裁字 ❌ |
| `--w-batch` | 70px | 差 46px ❌ |
| `--w-ctx` | 92px | 差 24px ❌ |
| `--w-profile` | 110px | 差 6px，且语义属「兜底档位」，挪用即语义串味 ❌ |
| `--w-cleaner` | 160px | 富余 44px，可用但语义属「净语配置目录」 ⚠️ |
| **新增** `--w-agg-window` | **128px** | 采纳。116px 内容 + 12px 余量；同时把「4.5 倍空框」压到「1.1 倍」 |

### 2.2 甲案（推荐·确定值，零 DOM 改动）

```css
/* AI 分析参数区三列宽度收敛（追记 D2026-1013-01）
   :nth-child 口径由 tests/test_gui_js_static.py:1009/3188「恰 3 组 field-col」
   及该钉 docstring 载明的顺序（提供方/模型/跨片窗口）共同锁定，顺序变则钉先红。 */
.ai-config-row > .field-col:nth-child(1) { flex: 0 1 auto; min-width: 170px; }
.ai-config-row > .field-col:nth-child(2) { flex: 1 1 240px; max-width: 560px; min-width: 240px; }
.ai-config-row > .field-col:nth-child(3) { flex: 0 0 var(--w-agg-window); }
```

- 第 1 列 `flex: 0 1 auto` → 收到内容宽（`跟随阶段 A（默认）` ≈164px），下拉沿用既有 `width:100%`（`:2174`）吃满列宽，**零特例规则**。
- 第 2 列吃余量但设 `max-width: 560px`，避免宽窗时模型下拉独吞整行、把生效行挤没。
- 第 3 列固定 128px。

**特异性核算**（落地须复核）：`.ai-config-row .field-col` = `(0,2,0)`；`…> .field-col:nth-child(3)` = `(0,3,0)` ✔ 覆盖。

### 2.3 乙案（内容自适应，更窄 12px）

```css
.ai-config-row > .field-col:nth-child(3) { flex: 0 0 auto; }
.ai-config-row > .field-col:nth-child(3) > .form-select {
    width: auto;                                  /* 让 select 取最长 option 固有宽 */
    min-width: var(--w-agg-window);              /* 下限 128px 兜底 */
}
```
特异性 `(0,4,0)` > 既有 `(0,3,0)` ✔。实宽 ≈116px（下限生效则 128px）。依赖 WebView2 对 `select{width:auto}` 取最长 option 的实现，确定性略逊甲案，列为可选微调。

### 2.4 渲染变化

跨片窗口框：520px → **128px**（1920 折叠态）；提供方框 520px → ≈170px；模型框 520px → ≤560px 且成为行内最宽项（视觉重心回到「分析模型」，与 owner 心智一致）。整行总高不变（顶置标签 19px + gap 4px + `.compact` 控件 30px ≈ 53px），**行数不变、页面高度零变化**。窄窗（1440 展开 824px 内宽）下三列 170+240+128+16 = 554px，仍单行放下。

## 3. 分析模型生效行：上移 + 与框平行

### 3.1 甲案（推荐·纯 CSS，零 DOM 改动，钉断言零变更）

关键认知：**导致折行的只有 `flex-basis: 100%`，不是 `order: 99`**。保留 `order: 99`（= 行内末位），去掉 `flex-basis`（= 不再强制换行），即可让生效行与三框同行；同时行内末位正是 owner 期望的「框右边」位置。

```css
.ai-config-row > #refineAiPrivacy {
    order: 99;                 /* 保留：行内末位（钉 test_gui_js_static.py:1004 逐字断言保留） */
    flex: 1 1 auto;            /* 替掉 flex-basis:100%——原值是强制折行的唯一成因 */
    min-width: 0;              /* 允许收缩，配合 ellipsis */
    max-width: 420px;
    align-self: flex-end;      /* .ai-config-row 为 align-items:flex-start（:2163），须显式改回 */
    margin-top: 0;             /* 原 :2180 的 margin-top:8px 对同行布局无意义 */
    overflow: hidden;
    text-overflow: ellipsis;
    white-space: nowrap;       /* 单行省略，杜绝换行把整行撑成两行 */
}
```

**对齐核算**（`--font-xs`=12px × `line-height:1.55` ≈ 18.6px 行盒；`.compact` 高 `--h-ctl-sm`=30px；列高 = 18.6+4+30 ≈ 53px）：控件占 y≈23–53，文字行盒高 ≈18.6。`align-self: flex-end` → 文字落 y≈34–53，文字中心 ≈43.5，控件文字中心 ≈38，**尚差 ≈5px**；落地时按真机截图补 `padding-bottom: 2px~4px`（属微调值，不预设死数）。若评议要求「数学对齐」，替代口径为 `align-self: flex-end` + 负 `margin-bottom: 5px`（仍不改 `--lh-tight`，不触行高钉）。

**宽度归属**（1920 折叠 1576px 内宽）：170 + 560 + 128 + 生效行 420 + 3×8 gap = 1302px ≤ 1576，余量 274px 沉淀在行尾（右缘留白，不撑框）。1440 展开（824px）：170 + 240 + 128 + 生效行 ≤ 262 + 24 = 824 → 生效行被压到 ≈262px，此时 §3.2 的中段省略成为必需（不是可选）。

### 3.2 文字简化规则（owner 原话：「文字过长导致错位可以调整简化分析模型文字描述」）

现状文本体例（`app.js:812`）：
`分析模型：独立配置 — lmstudio / lmstudio/qwen3.6-35b-a3b-uncensored-heretic-apex`（≈66 全/半角字符，12px 下 ≈400px+）。

**三级简化规则**（按序命中，先命中先返回）：

| 规则 | 条件 | 输出 | owner 示例代入 |
| --- | --- | --- | --- |
| R0 原样 | `len(model) <= 24` | 原串 | `gpt-4o-mini` |
| **R1 中段省略（推荐主规则）** | 其余 | `s.slice(0,12) + '…' + s.slice(-8)` | `lmstudio/qwe…retic-apex`（21 字符） |
| R2 provider+尾段（owner 备选口径） | 含 `/` 且段数 ≥2 | `首段 + '/…/' + 末段`（末段 >16 再走 R1） | `lmstudio/…/apex` |

推荐落地口径 = **R0 → R1**（最简、行为可预测）；若 owner 明确偏好「provider 名 + 尾段」的辨识感，改用 **R0 → R2**。二者不可叠加（会二次截断）。

**常量与位置**：`AI_MODEL_NAME_MAX = 24`、`AI_MODEL_HEAD = 12`、`AI_MODEL_TAIL = 8`，置于 `app.js` MSG 表之后的常量区（纯 JS 常量，不新增 data-i18n 键、不新增 MSG 键 → 契约恒空零影响）。

**改点（`aiRefreshEffective()`，`app.js:7099-7111`）**：

```js
const full = res.model || MSG.aiModelUnset;
const line = (m) => MSG.aiEffectiveLine(tag, res.effProvider, m)
                  + (note ? '｜' + note : '')
                  + (cloud.includes(res.effProvider) ? MSG.aiCloudNote : '');
el.textContent = line(shortModelName(full));   // 显示：简化串
el.title = line(full);                          // 悬停：全量串（沿用 bindDom 填 title 先例，零 data-i18n）
```

- `MSG.aiEffectiveLine` 模板与键名**一字不改**，只改入参 → `test_gui_js_static.py:3220-3225`（生效行文案全走 MSG 键 + 函数体内零中文字面量）继续绿；省略号用 `…`（非该钉点名的四个中文字面量之一）。
- `title` 为 JS 态填充，符合「新文案 JS 态填充」约定。

**渲染变化**：生效行由「第二行整行、宽度 100%」变为「与框同行、行内末位、≤420px 且单行省略」。窄窗下默认出现省略号（例：`分析模型：独立配置 — lmstudio / lmstudio/qwe…retic-apex` ≈ 330px），悬停可见全量。页面总高 **-53px**（少一整行）。

### 3.3 可选（语义澄清，非必需）

`#refineAiPrivacy` 现挂 `.hint-warn`（琥珀色，`style.css:1300`），语义本是「云端 provider 需确认」的警示。同行化后若琥珀长文本显得刺眼，可在 `aiRefreshEffective()` 内 JS 态切类：`el.classList.toggle('hint-warn', cloud.includes(res.effProvider))`，非云端时退回 `.muted` 灰。**零 id、零 data-i18n**，但属色彩语义变更，需 owner 点头。
