# 2.3.0 发布说明素材（D4，owner 发版时定稿；只写本版内容，禁未来计划/内部流程引用）

## 能力与变化

- **轻量安装包**：安装包不再内置日语语法词典数据，体积约 81MB → 33MB；日语语法提示所需词典数据在 GUI「引擎与模型 → 词典管理」一键下载（SHA256 校验+三源策略）。
- **词典管理改版**：三词典状态集中一处——空态引导条 + 下拉查看日/中/英详情（可用状态 pill/说明/安装目录/一键打开文件夹/下载按钮分级）。
- **字幕翻译主页更紧凑**：拖放区空态精简，添加文件后自动收起为单行，为文件列表与控制台腾出空间。
- **降级口径更新**：未下载词典数据时自动跳过句法分析（提示文案同步更新）。

## 能力边界（如实告知）

- 日语词典（sudachi）：EXE 安装版可在 GUI 下载；pip 用户可 `pip install -e ".[ja-dict]"`。
- 中文分词（jieba）：仅 pip 形态可获得（`pip install -e ".[zh]"`）；EXE 版暂不可下载。
- 英文分词：规则级内置，无需安装。
- 老用户升级：2.2.x 完整版安装的词典数据目录会保留（新包不再分发词典），可在 GUI 下载最新词典。

## 升级与兼容

- 断点恢复/指纹口径零变化；ja→zh 缺省流水线产物字节不变（去捆绑仅影响运行时词典数据来源，不影响字幕产物）。
- CLI `--dict-download` 与 GUI 下载链行为不变。
