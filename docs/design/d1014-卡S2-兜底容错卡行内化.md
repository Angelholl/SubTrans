## 改法（纯 CSS）

1. **行内化 override**（放 :3097 区之后、源序在后；选择器须 (0,3,1) 特异性+`!important` 压过 :1561 的列排，不改 :1561 本体——其他 form-card 依赖它）：

```css
.form-card.fallback-card:not(.stack) > label {
    display: flex !important;
    flex-direction: row !important;
    align-items: center !important;
}
```

（label 内 span↔控件 4px 间距由 :1561 的 `gap: var(--space-1)` 继承，不另写。）

2. **:3100 改写**（320px 限宽去=留白主因；240px 假下限随之删）：

```css
.form-card.fallback-card > label.path-row { flex: 1 1 auto; min-height: var(--h-ctl-sm); }
```

（:3097 本体 `align-items: flex-start; gap: var(--space-3);` 与 :3098-3099 两规则**原样不动**；基线对齐由 path-row 行高归一承接。）

3. **目录输入吃剩余宽**（新规则，覆盖 :1568 的 width:100%）：

```css
.form-card.fallback-card > label.path-row > .form-input {
    width: auto !important; min-width: var(--w-cleaner); flex: 1 1 var(--w-cleaner); }
```

4. **删除卡S1 过渡规则** `#refineCleanerConfigShow { min-width: var(--w-cleaner); }`（id 特异性 (1,0,0) 会压过本卡 class 规则 (0,4,1)，必须摘源规则；`--w-cleaner:160` token 本体保留）。
5. `.path-row` 本体（:1510-1516 nowrap）与 `.field-btn-row`（:1526）不动→浏览/打开随输入同行右缀 flush 右缘（阶段A 地址行语言）。
