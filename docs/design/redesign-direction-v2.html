3.1 方向稿 v2 所用 token 与组件规格 · 其余页面同一体系
Tier 1 零复议 / Tier 2 需 S6

表面三层（P0-1 · A1-② · Tier 2）

中栏 --surface #FFFFFF
左栏 / 右栏 --bg #F3F4F6
中栏内卡片 --surface-2 #F9FAFB
栏分隔线 --border-strong #D1D5DB

现状三栏为 #F9FAFB / #F3F4F6 / #F3F4F6（中↔右 1.000:1）。归一后栏间 1.108:1，靠"灰 / 白 / 灰"建立分区；只改层分配，不改任何色值。须与裁定表 B-18 一并拍板。

字级（P0-2 · Tier 1 维持 / Tier 2 归位）

页面标题18 / 700
区块标题--font / 700
正文与控件--font / 400
次级说明--font-sm / 400
元信息（路径 / 表头 / chip）--font-xs / 400

只有 14 / 13 / 12 三档 + 展示级 18；生产中 22 处 11px、2 处 10px、5 处 12.5px 全部归位到 --font-xs / --font-sm（Tier 2，需 S6）。禁止再出现裸 px 字号。

字重（P0-3 · Tier 1 零复议）

常规 400 —— 正文 / 控件 / 表格400
强调 700 —— 标题 / 按钮 / 表头 / chip700

Windows 仅 Segoe UI + 微软雅黑两档字重，生产 46 处 550/600/650 声明实际全渲染为 700、500 渲染为 400。本稿显式只声明 400/700，渲染结果与现状一致 → 不需复议；层级改由字级 + 颜色 + 留白承担。

按钮层级（P1-4）

主按钮底 --primary-strong #2563EB + 白字 = 5.12:1 达 AA（现状 #3B82F6 + 白字仅 3.68）。深色下底 --primary-strong #3B82F6 + --on-primary = --bg = 5.15:1。一个操作区只允许一枚主按钮。

状态 chip 四态（P0-5）

等待中 翻译中 已完成 可续传

琥珀文字改用 --status-warn #B26A00（4.09:1）替代 --warn #F59E0B（2.07:1 不达标）。若要达 4.5:1 需新增深琥珀 token → Tier 2，入归一包。

空态四态（P1-9）

图标 + 标题 + 一句说明 + 动作
四态齐全：首次进入 / 加载中 / 失败 / 暗色。可复用母版：校对页四态状态条、词典失败诊断。

凡"零静态文案、JS 态填充"的控件，必须同时设计三态兜底，否则 hook 失败即裸控件（空复选框 / 蓝空药丸 / 空圆角框）。
