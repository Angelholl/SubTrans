- **依赖**：聚合数据源批量读取层（TM 库/各片质量报告 json）；新 GUI 页（导航/页骨架/DOM 全套）；聚合统计口径定义（TM 命中率趋势/CPS 分布对比/风险密度等——**口径需需求方输入，当前无信号**）；钉⑤解冻（新页 id 量大）。
- **体量**：中大型（后端聚合接口+新页全套+测试+黑盒，估 3-5 人日起）。
- **前置**：owner 明确聚合诉求与口径 → 页面信息架构设计轮（design-expert+评议）→ 解冻预算表。
- **结论：无需求信号不进入实施**（本文档仅为留池项的成本/边界存照）。

## S5 配音链路

- **现状**：项目无任何音频生成能力——2.0 音频链路（漏听检测+快速试听）为**只读音频**，不产音频；无 TTS 依赖、无音色/时轴对齐相关代码。
- **依赖**：TTS 引擎选型（本地 vs 云端；体积/许可/离线约束——EXE 安装包体积预算敏感，2.3.0 刚完成 33MB 减重）；译文→配音文本适配（台词化改写）；**时轴对齐**（配音时长≠原时长→字幕重排或音频变速，算法未评估）；GUI 播放/导出链。
- **体量**：大型（全新子系统，估 1-2 周起，且横跨打包/许可/上游多面）。
- **前置**：owner 明确配音需求信号 → TTS 选型调研（含打包体积影响评估）→ 时轴对齐方案设计轮 → 立项评议。
- **结论：无需求信号不进入实施**（TTS 上游、打包体积、模型依赖均为未评估盲区，此刻产方案=脑补）。
