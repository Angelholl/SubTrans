# 单件卡：C22 听点标注器——声源组合勾选细化（C(4,0)~C(4,4) 穷举 17 态）

> 决策依据：owner 2026-10-13 试听发现"背景声+道具声+小声人声"混合段二元判定边界模糊，指示"对背景声+道具声+人声进行排列组合细化，我来勾选对应哪个"。语义基线=D2026-1009-02（真值=确有台词）+程序侧纯拟声判弃口径（呻吟≠台词）。C22 批，依赖卡2 工具（75cc69f+a259386）。
> 执行者：OpenCode。只 commit 不 push；卡外问题即停待裁决。

## 根因

二元判定（有对话/无对话）在混合声源段丢失信息：owner 实际听到的是多声源叠加（人声+道具+背景），二元勾选迫使其在小声人声段凭"后果担忧"而非"听感事实"作答。需把听感事实（声源组合）与派生真值（是否台词）分离：owner 勾组合，规则派生真值。

## 改法（功能规格）

### UI（首轮与复标轮同构）

- 三个作答按钮改为 **17 个声源组合按钮，按声源数分组穷举**（C(4,0)~C(4,4) 全排列，owner 点名要求显式穷举而非勾选框合成）：
  - **无声源**：🔇 静音（无任何声源）
  - **单声源 C(4,1)**：台词｜呻吟喘息｜道具声｜背景声
  - **双声源 C(4,2)**：台词+呻吟｜台词+道具｜台词+背景｜呻吟+道具｜呻吟+背景｜道具+背景
  - **三声源 C(4,3)**：台词+呻吟+道具｜台词+呻吟+背景｜台词+道具+背景｜呻吟+道具+背景
  - **四声源 C(4,4)**：台词+呻吟+道具+背景
- 页首名词解释一行：台词（含小声/气声台词）/呻吟喘息（非言语人声）/道具声（衣物门脚步等）/背景声（音乐·环境音）；
- **派生判定着色**：组合含「台词」→ 按钮绿色系+角标「有对话」；不含 → 中性色系+角标「无对话」（静音=无对话）；分组头带图例「含台词=有对话」，所见即所得；
- **单击即提交**并自动跳下一条（恢复 v1 一次点击节奏）；「⏭ 稍后再听」保留为次按钮；
- 复标轮：同款 17 钮**盲标**（不回显首轮选择）；复标只按派生 label 计，无 skip。

### 数据模型与迁移

- `records[].sounds = {speech, moan, prop, bg}`（bool×4）新增字段；`label` 字段保留并由 sounds 派生（speech=true→"yes"否则"no"），**向后兼容**：
  - 旧记录（有 label 无 sounds）：UI 显示「旧口径已标：有对话/无对话（可重答）」，作答新组合即覆盖 label 并补 sounds；
  - state.json 读取零迁移脚本（缺 sounds 视为 null，不崩不丢）；
- 复标一致率按**派生 label** 计算（两轮派生相同=一致），口径与协议（≥90%）不变。

### merge 与统计

- `c22_manifest_labeled.json` 输出不变（labels bool 数组=派生值，harness 零改动）；
- merge 控制台摘要新增**声源组合分布统计**：17 组合各自计数 + 「台词+道具/背景叠加」组合单列小计（校准报告外的观察数据）。

### 测试钉（先红后绿）

- 钉1 派生规则：sounds.speech=true→label yes；仅 moan/prop/bg→no；
- 钉2 旧记录兼容：label 有值无 sounds → 读取不崩、UI 状态"旧口径"、重答覆盖；
- 钉3 17 组合按钮穷举与向量映射：C(4,0)~C(4,4) 每按钮→唯一 sounds 向量，含台词组合派生 yes、其余 no；
- 钉4 复标一致率按派生值（构造两轮 sounds 不同但派生相同=一致）；
- 钉5 merge 分布统计（含台词+叠加组合单列）与 labels 数组=派生值；
- 钉6 /api/answer 接收 sounds 且原子落盘。
