2. 三列收敛（`:nth-child` 定位，禁加类）：
   ```css
   /* 卡R1（D2026-1013-01 第五轮反馈）：AI 分析三列按内容定宽，跨片窗口框不再等分整行 */

   .ai-config-row > .field-col:nth-child(2) { flex: 1 1 220px; min-width: 150px; }   /* 分析模型列吃余量（model-trio 三件） */

   ```
   （第 1 列分析提供方 auto 宽由内容定、第 2 列分析模型吃余量、第 3 列跨片窗口定宽 128px；窄窗 wrap 仍由父容器 flex-wrap 既有承接。）
