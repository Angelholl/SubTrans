# d1015 残余批 · 卡I · P2-5 钉3 冻结集收缩 + active-text 暗侧钉（+负控红证据）

> 以下命令均在项目根目录执行。前置：卡H 已落地（CSS token 化在 HEAD）。**卡面行号参考，执行以 re-grep 定位。**

## 根因

卡H 把组件内两枚蓝阴影字面收进 :root token 后，钉3 冻结集 `_FROZEN_COLOR_DISTINCT` 内的旧字面成为防回潮漏洞（组件再写回同字面不会红）；暗侧 active-text 修复（卡H）也无钉保护。

## 改动文件（仅 1 个）

1. `tests/test_gui_js_static.py`

## 改法

1. `_FROZEN_COLOR_DISTINCT` 收缩：移除 `"rgba(59,130,246,.35)"` 与 `"rgba(37,99,235,.3)"`（保留 `#fff` 与 `"rgba(0, 0, 0, 0.5)"`）。
2. 新增收紧断言（加在钉3 测试内或紧随其后）：组件 scope（既有 `_style_css_component_scope` helper）内不得含 `rgba(59,130,246,.35)` 与 `rgba(37,99,235,.3)` 任一字面。
3. 新增钉 `test_active_text_dark_aa_pinned`：style.dark.css `:root` 块含 `--active-text` 覆盖声明且值为 `var(--primary)`。
