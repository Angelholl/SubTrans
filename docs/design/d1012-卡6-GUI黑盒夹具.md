# 单件卡：GUI 黑盒夹具（stub 桥+本地伺服，Temp 瞬态不入库）

> 决策依据：D2026-1012-01 阶段 4 验收前置 + 卡3/卡4 GUI 黑盒补验需求（主审 2026-10-12 指示）。
> 执行者：OpenCode（longcat-2.5-preview-free，本卡兼当该模型胜任力试金石）。产物留 Temp 不入库，只提交卡片执行记录。

## 根因（为什么要建）

GUI 为 pywebview 桌面形态，浏览器自动化无法直连；此前黑盒走查靠临时 stub 桥未沉淀，卡3（switchTab 六钩子）/卡4（active token）的"视觉零变化+行为零变化"黑盒复核因此挂起。需要一个可复用夹具：浏览器里加载真实 index.html+app.js+style.css，pywebview 桥全部打桩。

## 产物（两文件，全部在 `Temp/gui-blackbox/`，禁止写入仓库其他位置）

1. `Temp/gui-blackbox/stub_bridge.js`：定义 `window.pywebview` 桩——先 grep `subtransjav/webview_gui/assets/app.js` 里 `pywebview.api.` 的全部方法名，启动关键路径（初始化/设置读取/strings 加载类）逐个给安全假值（空对象/空数组/合理默认），其余方法用 Proxy 兜底 resolve 空对象并 console.debug 记录调用名。
2. `Temp/gui-blackbox/serve.py`：stdlib http.server——伺服 `subtransjav/webview_gui/assets/`，并在返回 index.html 时于 app.js 之前注入 `<script src="/stub_bridge.js"></script>`（动态注入，不改仓库 index.html）；端口 8123。

## 先红后绿

- 红：无桥直接浏览器开 index.html → console 有 pywebview 未定义类错误、初始化中断（记录截图/日志即可）。
- 绿：`python Temp/gui-blackbox/serve.py` 后浏览器开 http://127.0.0.1:8123/ → console 零未捕获错误；左侧 7 个 TAB 点击可切换（.tab-page.active 跟随）；暗色开关可切。用浏览器自动化实测并截图存 `Temp/gui-blackbox/shots/`（light/dark 各一张）。
