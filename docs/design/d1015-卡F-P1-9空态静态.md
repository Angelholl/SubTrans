## 根因

空态/JS 态零设计：JS 未跑/失败时校对页出现空药丸幽灵钮、质量页导读引导藏在闭合 details 内首屏不可见、高级页第 4 卡白卡空框、引擎页模型下拉静态空占位（格逐格勘验见规格 §4.1）。

## 改动文件（仅 2 个）

1. `subtransjav/webview_gui/assets/style.css`
2. `subtransjav/webview_gui/assets/index.html`

## 改法

**格3① 空钮收形（校对页）**——style.css 新增（放 .dropzone 家族规则附近）：
```css
.review-det-tools button:empty { display: none; }
```
（勘注：`#reviewDropzone .dz-actions` 两枚导入钮经卡B/卡L 已常驻图标，永不 `:empty`，规则无对象——不写，防死规则。）
前置核实（re-grep 后执行）：校对页 `.review-det-tools` 内按钮若标签内含空白字符（空白文本节点会使 :empty 不命中），把**该批按钮**的标签内纯空白删为真空元素（`<button …></button>`），逐处列进执行记录；translate 页按钮有实文不受影响。

**格3② 下半屏兜底行（校对页，语境中性键，勿用 empty_hint）**：
- 先读 review.js 确认检测结果列表容器（re-grep `review-detections` 或同族）的渲染方式：
  - 若为 innerHTML 覆盖式渲染 → 在该容器**内部**预置 `<p class="muted" data-i18n="no_files_selected">暂未选择文件</p>`（JS 首次渲染自动冲掉，零接线；no_files_selected='暂未选择文件' 语境中性）；
  - 若为 append 式 → 本子项登记不修（写入执行记录），只保留格3①。

**格4 质量页导读 details 首屏可见**：index.html `<details id="refineGuideViewer">` 开标签加 `open` 属性（`<details id="refineGuideViewer" open>`；零 id/键/class 变更，属性新增不入快照；JS 加载成功本就 open，失败/空态保持展开可见「暂无导读数据」引导）。

**格7 静态半（引擎页模型下拉）**：两处空占位 option（re-grep `<option value="" disabled selected></option>`）文本改为 app.js MSG 表 `model_list_empty_hint` 的**现值逐字拷贝**（先 grep 该键值再粘贴，键值本身不改；运行时 JS 会覆写/替换 option，静态文本只服务首帧）。

**格14① 高级页第 4 卡空子件收形**——style.css 新增（紧跟格3① 规则后）：
```css
[data-testid="encode-adv-group"] .group-title:empty,
[data-testid="encode-adv-group"] .muted:empty,
[data-testid="encode-adv-group"] .btn:empty { display: none; }
```
（作用域已按评议收窄到该卡；卡内四元素已勘验为真空元素，:empty 可命中。）

**格14② 数据目录路径占位**：`#dataRootCurrentPath`（re-grep）空 span 文本置「—」（与系统状态卡占位同语言，零键；JS 覆写核验在卡G）。
