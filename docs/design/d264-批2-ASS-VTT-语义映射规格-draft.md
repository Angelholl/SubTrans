# 2.6.4 批2：ASS/VTT→SRT 语义映射规格（草稿 v0.1，预研产物）

> D2026-1003-05 / 预研依据：spike/pysubs2_result{,2,3}.txt（pysubs2 1.8.1 实测）。
> 本文档为开工门①的画押件：每项含「规格决策（草案）+ spike 证据 + 金样本验收要点」，
> owner 逐项画押后方门开。标注 ⚑ 的为必须 owner 裁决的画押点。

## 1. 编码探测次序 ⚑

- **决策（草案）**：转换包装层自持探测梯，**禁用 pysubs2 自动探测**——
  ①UTF-8 BOM → ②UTF-8 严格解码 → ③CP932（Shift-JIS，日源 ASS 常见）严格 →
  ④GB18030 严格 → ⑤全部失败＝整文件拒绝并展示尝试明细（吞错可见化，不猜拉丁兜底）。
- **spike 证据**：GBK 无 BOM 样本走库自动探测直接 `UnicodeDecodeError`；显式
  `encoding="gbk"` 解析正确。
- **验收要点**：金样本库含 UTF-8/UTF-8-BOM/CP932/GB18030 各 ≥1 例，产出文本与
  基准逐字一致；编码探测结果随告警展示，用户可在 GUI 重选编码重导。
- **画押点**：③④次序（日源优先 CP932 还是中源优先 GB18030）。

## 2. ASS Format 行驱动解析

- **决策（草案）**：依赖 pysubs2 按 `Format:` 行解析（头驱动，禁位置硬编码）；
  包装层对解析期 `RuntimeWarning`（如 "Failed to parse layer"）计数进告警清单。
- **spike 证据**：标准序与 SSA `Marked=` 变体序均正确解析；缺字段触发告警并用默认值。
- **验收要点**：金样本含字段增删/换序各 1 例，文本提取与基准一致；告警计数 >0 时
  质量报告留痕。

## 3. VTT 非载荷行清单

- **决策（草案）**：以下内容不入载荷——文件头 `WEBVTT` 行、id 行（独立于时间轴行
  的标识行）、`NOTE` 块、`STYLE` 块、`REGION` 块、cue 内 `align:/line:/position:`
  等定位设置（随时间轴行，丢弃不告警）。
- **spike 证据**：pysubs2 正确排除 NOTE/STYLE/REGION/id 行（3 事件干净产出）。
- **验收要点**：金样本含全部五类非载荷行，产出 SRT 不含任何一类痕迹。

## 4. 换行三态映射 ⚑

- **决策（草案）**：随库行为——`\N`→换行、`\n`→换行、`\h`→空格。
- **spike 证据**：`硬换行\n第二行`（\N 保留为真实换行）、`空格 和软换行`（\h→空格、
  \n→换行；库不区分软硬）。
- **验收要点**：金样本含三符号各 1 例，对照产出逐字断言。
- **画押点**：`\n`（ASS 语义为软换行）是随库→换行，还是后洗→空格；默认随库。

## 5. voice span（`<v Name>`）多语轨 ⚑

- **决策（草案）**：丢弃标签、文本归一入单轨，**说话人名整段丢弃**（不做前缀保留，
  不做多轨合并输出）——与库默认行为一致，包装层零额外成本。
- **spike 证据**：`<v 佐藤>语音一文本</v>` → 产出 `语音一文本`，名字整段消失。
- **验收要点**：金样本含 voice span 例，产出无标签且无名字残留；若 owner 选
  "保留为前缀"则加 `【佐藤】` 前缀规则（包装层 +5 行）。
- **画押点**：丢弃 vs 前缀保留。

## 6. 厘秒→毫秒换算与边界防重叠

- **决策（草案）**：ASS 厘秒 ×10 精确换算（无取整面），零填充由库保证；包装层对
  **产出做静态断言**（全部时间戳匹配 `\d{2}:\d{2}:\d{2},\d{3}`）作保险带。
  相邻 cue 重叠修正：`end` 不动、后一 cue `start` 顺延至前一 `end`（方向写死），
  修正计数进告警清单。
- **spike 证据**：`0:00:00.90→00:00:00,900`、`0:00:01.05→00:00:01,050` 由库保证。
- **验收要点**：金样本含 0.9s/1.05s 边界例+重叠例各 1，静态断言通过且修正计数正确。

## 7. 内嵌时间戳标签与 roll-up captions

- **决策（草案）**：VTT 逐字高亮时间戳标签（`<00:00:04.500>`）与 `<c>` 类标签——
  标签剥离（`<c>` 库已剥，**时间戳标签库不剥，包装层后洗正则兜底**——spike 实证
  泄漏）；roll-up captions 无 SRT 承载，**显式忽略不报错**（其 REGION/line 定位面
  随第 3 项丢弃）。
- **spike 证据**：产出 `'<00:00:04.500>内嵌时间戳与高亮文本'`——时间戳标签泄漏实证。
- **验收要点**：金样本含时间戳标签例，产出零残留（正则断言）；roll-up 样不报错。

## 8. 不可解析行抢救 + 告警 + 临时 SRT 生命周期 ⚑

- **决策（草案）**：
  - 坏行**逐条抢救**：pysubs2 静默跳过坏行但**会留空事件**（spike 实证产出含 ''），
    包装层必须①前置逐行预洗计数②后置剔除空事件③坏行行号+原文进告警清单（吞错
    可见化纪律）；
  - **临时 SRT 生命周期**：转换产物落输入同目录，命名 `<原名>.<格式>.conv.srt`，
    随跑批产物清单登记并**永久保留**（作为可追溯输入，体积小；resume 语义自动
    成立——重跑指向同一文件，指纹一致）；不做自动删除。
- **spike 证据**：坏行样本产出 `['正常行前', '', '正常行后']`。
- **验收要点**：金样本含坏行例，告警清单含行号与计数，空事件零残留；conv.srt 在
  产物清单与 resume 路径中语义与普通 SRT 输入完全一致（指纹计算点=conv 后文件）。
- **画押点**：conv.srt 永久保留 vs 成功后删除（草案=保留）。
