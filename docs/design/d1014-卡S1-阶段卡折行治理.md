### 2. style.css

a) **新增 3 个宽度 token**——落「组件定宽 token 区」（`--w-agg-window` 那一小节之后；**不进**上方「index.html 内联样式逐字引用」区，新 token 无内联引用。主审裁量，修正设计稿的落区建议）：

```css
--w-stage-model: 140px;   /* 阶段模型框下限=flex basis（卡S1；--w-model 不动防角色卡连带） */
--w-stage-unit: 520px;    /* 单元二行破下限（实测 486+34 余量） */
--w-stage-key: 240px;     /* API Key 三件原子组下限（label42+140+36+gap16=234+6） */
```

b) **删 `.alt-row` 规则块（:1593-1599）**，原位换两规则：

```css
.stage-unit {
    flex: 1 1 0;
    min-width: min(var(--w-stage-unit), 100%);
    display: flex;
    align-items: center;
    gap: var(--space-2);
    flex-wrap: wrap;
}
.stage-key {
    flex: 1 1 0;
    min-width: var(--w-stage-key);
    display: flex;
    align-items: center;
    gap: var(--space-2);
}
```

c) **status 选择器组（:1584-1591）仅摘除 `.alt-row .muted,` 一行**（死选择器；`.stage-row .muted` 与 `.stage-row .stage-test-status` 两行及 order:99/basis:100% 主体不动）。

d) **:1604 拆分**：`#refineS1Model, #refineS3Model, #refineCleanerConfigShow { min-width: var(--w-model); }` 改为两规则——

```css
#refineS1Model, #refineS3Model { min-width: var(--w-stage-model); }
#refineCleanerConfigShow { min-width: var(--w-cleaner); }
```

（后者为卡S2 的过渡态：卡S2 将删除本行并在 class 规则里带 `min-width: var(--w-cleaner)`；id 规则不摘会压过 class 规则，故必须由 S2 摘。）

e) `.stage-row` 本体（:1574-1583）、`:1602-1603`、`:1605` 卡Q 规则与注释、`--w-model`/`--w-alt-row` token **全部原样不动**（`--w-model:200` 不动——index.html:552 角色卡内联引用同 token）。
