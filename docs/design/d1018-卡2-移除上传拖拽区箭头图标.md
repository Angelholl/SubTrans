非交互执行环境（question 工具不可用），实测发现卡面与现状四处偏差，按卡面四重冗余锚点（行号 932-934 / 三条 path d 值 / 文案「开始校对」/ review 家族 CSS）的交集自洽解读为 `#reviewDropzone` 图标组执行（方案 A），如实声明：
