## 背景（主审勘探，卡面自足）

- 现状：`#tab-translate` 内两卡片纵向弹性分配——文件卡 `#tab-translate > .card { flex: 1 1 60%; }`（style.css:663 附近）与 `#tab-translate .console-collapsible:not(.collapsed) { flex: 1 1 40%; min-height: 180px; }`（style.css:891 附近）。60/40 为卡F（D2026-1013-01）定的**默认基准**；两者之间的 DOM 顺序即文件卡在上、Console 在下（以 index.html 实际结构为准，执行者先确认容器与相邻元素）。
- 本卡目标：两卡片交界处加一条**可拖拽分隔条**，拖动改变上下比例，比例写入 `localStorage`（key 建议 `subtransjav.translate.split`，值=文件卡 flex-basis 百分数字符串），下次进页恢复；不破坏既有约束——文件卡 `min-height:0`、Console `min-height:180px` 保底、`.collapsed` 折叠态优先（折叠时分隔条隐藏或禁用，二选取一并在注释写明）。
- 既有惯例：localStorage 键形态参照 `subtransjav.aside.collapsed`（assets/app-init.js:42）；合成环境 localStorage 可用的前提是非 private 断言路径，已有先例（右栏折叠记忆）。

## 改法要点

1. CSS 变量 `--translate-split` 默认 `60%`；文件卡 `flex: 1 1 var(--translate-split)`；Console 保持 `flex: 1 1 40%`（或 `calc(100% - var(--translate-split))`，取实现最简者并在注释写明）。
2. 拖拽=纯前端：`e.preventDefault()` 允许；**禁 stopPropagation**（d1021-卡1 缺陷B 同源教训：document 级 pywebview 桥靠冒泡）。
3. 折叠互斥：`.console-collapsible.collapsed` 或右栏折叠时拖拽不生效（display:none 或 guard 均可）。
4. clamp [25,75]：越界值丢弃（写入前 clamp），localStorage 读到非法值回退 60。

### 遗留问题

1. **真机拖拽未验证**（合成环境无真拖拽）——分隔条为纯前端 mouse 事件，真机走查挂账 owner；`--dur` 过渡与 WebView2 光标形态（`row-resize`）同样待真机确认。

3. **键盘可达性**：`role="separator"` 未挂 `tabindex`/方向键支持（卡面仅要求 mouse 会话；挂 focusable 而无键盘处理反成 a11y 空承诺，故本批不挂）。
4. **拖动分母口径**：比例按「文件卡顶 → Console 底」实测像素计算，未把分隔条自身 8px 高度扣除（误差 <1.5%，clamp 区间内无感）；如需像素级精确可另开微调卡。
