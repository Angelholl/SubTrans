# d1021-卡1：拖拽文件无法真正加载——确诊＋修复（P1-6 独立批 · 件A）

以下命令均在项目根目录执行。

## 背景（主审已勘探，卡面自足）

真机（v3.0.4 已发布包）实测：把字幕/视频文件拖入 GUI 窗口，无法真正加载。拖放链现状（主审静态勘探结论，执行者可直接采信省勘探时间，但根因未定）：

- python 侧承接：`subtransjav/webview_gui/main.py:195` `on_drop_event`（document 级 drop，`main.py:241` DOMEventHandler 注册；dragenter/dragover=空 handler `main.py:239-240`）。取 `file['pywebviewFullPath']`，后缀白名单 `main.py:212-213`＝(.srt/.ass/.ssa/.vtt + 5 视频后缀)，`register_session_paths` 后 `evaluate_js("ReviewUI.onDroppedFiles(...)")`。
- JS 侧分流：`subtransjav/webview_gui/assets/review.js:328` `onDroppedFiles`——非 tab-review 转发 `FileListManager.addDroppedFiles`（`assets/app-file-list.js:74`，字幕四后缀入 `AppState.selectedFiles`）；tab-review 内 `setVideoPath`/`setSrtPath`。
- JS 本体 drop 监听只有视觉高亮（`review.js:260-262`、`app-file-list.js:47-71`，均 preventDefault+stopPropagation）。
- **已实证缺陷①（必修）**：`review.js:128` `REVIEW_SRT_EXTS: ['.srt']` 与 main.py:211 放宽口径（.ass/.ssa/.vtt）不同步——校对页拖入 .ass/.ssa/.vtt 被静默丢弃（2.7.2 件1 口径统一漏了这半边，同键族消费点未全查的老坑形态）。
- 疑点清单（按优先级，须逐一取证后定根因）：
  1. 真机 gui.log 证据：`dom_events_bound`/`dom_events_bind_failed`/`drop_event_error`（main.py:232/242/245）是否有打印——绑定失败或 drop 期异常直接定位；
  2. `webview.start(private_mode=True)`（main.py:502）+ WebView2 组合下 pywebviewFullPath 注入是否失效（此组合 3.x 才有，2.6.1 黑盒验证时点不同）；
  3. `main.py:400` 附近 `'easy_drag': True` 所在 window 配置是否与页内 HTML5 drag 冲突；
  4. document 级 dragover 空 handler 未 preventDefault——拖放落点若不在 fileList/dropzone 上（如页面空白处），drop 默认行为=WebView2 打开文件而非导入。
- 3.1 UI 重塑（四卡＋残余批）未触碰上述链路；app.js 拆分批 1-4 对 review.js/app-file-list.js 为零改动切出。回归引入点不明=更需证据驱动，禁盲改。
