# d1016 卡B · 校对页右栏解除强制隐藏改「折叠态起步」（右缘保留折叠/展开钮）+ 钉

> 以下命令均在项目根目录执行。需求澄清（owner 2026-10-16 二次指认）：校对页要有与质量与建议页同款的右栏「折叠/展开」按钮（`.aside-toggle-btn`，实机呈右缘 « 把手，点击展开/收起右栏）。现状=校对页激活时 JS 给 `.workbench` 挂 `no-aside`（style.css L418-419 display:none 整个右栏，按钮随之消失）。**卡面行号参考，执行以 re-grep 定位。**

## 根因

`review.js` `_bindTabWatcher`/`_syncWorkbench`（re-grep，现 L268-286）在 active tab 为 `tab-review` 时给 `.workbench` 挂 `no-aside` → CSS 把 `.aside` 整体 `display:none`，全局折叠/展开按钮位于 `.aside` 内部随之被隐藏——校对页因此不存在任何折叠/展开侧栏的入口。质量页等其他页走卡G2/卡N 的 `aside-collapsed` 折叠态（44px 把手轨 + « 钮），可正常折叠/展开。

## 方案

校对页**不再挂 `no-aside`**，改为**进入校对页时强制右栏折叠态**（`aside-collapsed`，即 owner 图一的形态：右栏收起、右缘 « 折叠/展开钮保留可点）；离开校对页恢复进页前的折叠状态。校对工作区「全宽起步」语义由强制折叠保住；用户在校对页可随时点把手展开右栏（内容=全局右栏现内容，零新增）。

## 改法

### 1. review.js

对象字段区（re-grep `_blocks:` 等字段声明处）新增 `_asidePreReview: null,`。

`_syncWorkbench`（re-grep，现 L276-282）等价重写 + 新增 `_syncAsideAria`：

```javascript
    _syncWorkbench() {
        const wb = document.querySelector('.workbench');
        if (!wb) { return; }
        const tab = this.getActiveTab();
        if (tab === 'tab-review') {
            // d1016-卡B：右栏折叠态起步（右缘保留折叠/展开钮），校对工作区全宽语义
            if (this._asidePreReview == null) {
                this._asidePreReview = wb.classList.contains('aside-collapsed');
            }
            wb.classList.add('aside-collapsed');
            this._syncAsideAria(true);
        } else if (this._asidePreReview != null) {
            // 离开校对页：恢复进页前状态（快照制，不读 localStorage，避免
            // private 模式默认分歧与卡G2 持久化串扰）
            wb.classList.toggle('aside-collapsed', this._asidePreReview);
            this._syncAsideAria(this._asidePreReview);
            this._asidePreReview = null;
        }
    },

    _syncAsideAria(collapsed) {
        // 卡G2 handler 只在点击时写 aria；进页强制折叠态需同步补齐
        document.querySelectorAll('.aside-toggle-btn').forEach((b) => {
            b.setAttribute('aria-expanded', collapsed ? 'false' : 'true');
        });
    },
```

要点：快照制恢复（`_asidePreReview`），**不读 localStorage**——私有模式无记忆时不会与卡G2 启动默认（innerWidth≤1240 折叠）打架；用户在校对页手动展开仍走卡G2 既有 handler（含持久化），不特判。`no-aside` 在 review.js 全库仅 L269 注释与 L280 挂载两处，一并摘除。
