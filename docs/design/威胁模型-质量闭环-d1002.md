> 状态：按 owner 追认口径落盘（2026-10-02），随批 1 批清单二级评议送审。

## 1. 范围与数据流

批 1 闭环两条出网链路（其余全部本地）：

```
[链路 A｜AI 分析（既有，2.5.0 口径不变）]
  质量报告 txt(截断后) + 导读 json + 术语冲突观察 CSV 摘要
    → 分析 provider（缺省=跟随阶段A；云端须显式选择）→ 建议件 json（本地落盘）

[链路 B｜批量修复（本批新增）]
  选中导读条目 {timing, current_text, 源文（--action-source 命中时发送
    完整源文行；未命中时为 ≤40 字导读摘录）, 处理要点 hint}
    + 目标语言指令 → 修复 provider（缺省=阶段B/槽 s3；云端须阶段B 显式配置）
    → 新译文 → 本地质量门 → 终稿+导读+台账（均本地）
```

**明确不发送**：音/视频媒体（批 3 另评）、TM 库全文、词库文件全文、
角色卡内容、系统路径信息、任何密钥材料。

> 补记（2026-10-07，D2026-1007-01）：批量修复确认框改为展示现译全文，
> 全文来自 GUI 前端本已持有的导读 json（read_output_artifact 读取），
> 后端摘录限长仅约束回包形状——本节出域暴露面不变。

## 2. 服务商与端点面

- 缺省本地：lmstudio/ollama（跟随阶段设置）。云端（deepseek/siliconflow/zen）
  仅当用户在阶段设置或 AI 分析独立下拉中**显式选择**时启用（条件②）。
- 批 1 延续既有口径：AI 分析独立配置不支持 custom（无默认端点，后端兜底拒绝）。
- 端点旗标仅显式非空才传；不出现在日志/错误摘要明文之外的面。

## 3. 密钥面

- 密钥只经两条通路：**DPAPI 密钥库**（store_secret/read_secret，本机当前用户）
  与**子进程环境变量注入**（变量名白名单：DEEPSEEK_API_KEY/OPENCODE_API_KEY/
  SILICONFLOW_API_KEY/CUSTOM_API_KEY，与 RefineConfig.resolve_api_key、
  start_translation 注入表一致）。
- 禁令：密钥不写命令行参数、不写日志、不进 stderr_tail 摘要、不回传前端明文。
- 批 1 新增代码零新增密钥存储点；复用 refine_ai_analyze 同槽注入模式
  （api.py `_AI_PROVIDER_KEY_ENV`）。

## 4. 确认与知情面（条件③）

- 云端分析：沿用发送前 `AppModal.confirm`（app.js refineAiAnalyze 既有）。
- 批量修复新增确认弹窗（无论本地/云端都弹）：待修条目数、分类明细、
  修复服务商、预估调用次数（N 次翻译 + 复验 1 次分析）、云端时追加计费提示。
- 无任何无人值守自动写盘：修复执行必然发生在用户点击确认之后；
  dry-run 缺省语义在 CLI 侧保留（GUI 传 `--apply` 前已过确认）。

## 5. 写面与回滚

- apply 写入范围：终稿 SRT、导读 json（状态刷新）、重翻台账
  `{stem}_重翻记录.json`——三者均在数据根/输出目录内。
- 写序硬约束（既有，批 1 不动）：**台账先于终稿**；恒等式断言
  （条目数/timing/未选中块逐字节）失败即零落盘。
- GUI 批 1 不新增任何绕过台账的直写路径；自动回滚不做（台账手动通道保留，
  逐条勾选回滚归批 2 台账视图）。

## 6. 攻击面与防护

| 面 | 防护 |
|---|---|
| 路径注入/越权读取 | 一律 `_validate_user_directory` + 后缀白名单（`_质量报告导读.json`/`_质量报告.txt`） |
| 子进程面 | spawn_refine_cli 统一入口：CREATE_NO_WINDOW+UTF-8 强制+超时（批 1800s）+杀树原语 |
| LLM 响应面 | 修复走本地质量门（非空/异于现译/is_fluent_target），失败记台账不落盘；响应只写数据根内文件 |
| 提示注入（报告内容含恶意指令） | 分析输出仅作建议展示不自动执行；修复目标由本地导读 items 驱动，报告文本不改变执行清单 |
| DoS/洪水 | 单批 ≤50 条硬上限；CPS 类行动条目生成侧 max_items=20 既有 |

## 7. 留存与出域

建议件/台账/导读/终稿全部落本地数据根；无遥测、无崩溃上报、无匿名统计。
云服务商侧的数据留存/训练策略不在本项目控制内——README 与确认弹窗已提示
"云端按其隐私政策处理"，用户自选服务商自担该层责任（2.5.0 发版说明既有口径）。

## 9. 残余风险与接受

1. LLM 修复质量风险：质量门+复验差异对比兜底；误伤可依台账回滚（手动）。
2. 云端计费失控：单批上限+预估进弹窗（成本护栏成文，批清单第 4 节）。
3. 提示注入残余：分析文本可能诱导建议文本异常——建议仅展示、人工确认后才
   进入修复清单，且修复清单由本地 items 决定，注入不扩大执行面。
