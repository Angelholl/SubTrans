## 背景/根因

终稿唯一格式为手写 SRT（`filters.py:56 build_srt`），导入侧 ASS/VTT 样式不可逆丢弃；成品需可选输出 ASS/VTT 容器件（样式=显式默认集，对齐压制 force_style 语义）。终稿 SRT 共 4 写点（`pipeline_v2.py:1607`、`action_retranslate.py:558`、`api.py:6124/6563`），本卡覆盖前两处，后两处批2 接。一致性契约：**附加件一经产生，任何终稿写点同步再生；写点不凭空新增**（cfg 旗标 ∪ 已存在附加件）。

## 改动文件与改法

1. **新建 `subtransjav/refine/output_formats.py`**：
   - `EXTRA_FORMATS = ("ass", "vtt")`；
   - `build_extra_text(fmt: str, entries: list[dict]) -> str`：entries 结构 `{"index","timing","text"}`（`filters.py:49-52` parse_srt 产出同构），timing 串 `HH:MM:SS,mmm --> HH:MM:SS,mmm` 解析为 ms；
     - **ASS**：pysubs2 `SSAFile`，**显式构造**样式（禁依赖默认 Arial）：`PlayResX=1920/PlayResY=1080`，样式字段逐字对齐 `hardsub.py:119-123` `_FORCE_STYLE_TEMPLATE`（Fontname=Microsoft YaHei,Bold=1,PrimaryColour=&H00FFFFFF,OutlineColour=&H00000000,BorderStyle=1,Outline=2.5,Shadow=2.5,Alignment=2,MarginL=10,MarginR=10,MarginV=20），`Fontsize=48`（模板 font_size 默认 22 为 ffmpeg 像素口径，ASS 按 PlayRes 1080 基准取 48，口径钉死在测试）；
     - **多行文本必经 `SSAEvent.plaintext` setter**（`\n`→`\N`；直写 text 产出破损 ASS，pysubs2 1.8.1 实证）；
     - **出口前剥残留 override**：正则 `\{\\[^}]*\}` 清 `{\...}` 串（两格式同规则）；
     - **VTT**：文本先转义 `&`→`&amp;`、`<`→`&lt;`、`>`→`&gt;`（pysubs2 VTT writer 不转义，实证）；
     - **零时长规范化**：`end<=start` 时 `end=start+1`（VTT 规范 end>start）；
     - ASS 时间戳为 centisecond 精度（`H:MM:SS.cc` 10ms 舍入）属 pysubs2 固有，不额外补偿；VTT 保留 ms。
   - `existing_extra_formats(final_path: str) -> tuple[str, ...]`：同目录 `{去.srt名}.ass/.vtt` 在场探测；
   - `sync_extra_outputs(final_path: str, entries, formats) -> list[str]`：`final_path` 去 `.srt` 换扩展写 `{stem}_final_xx.ass/.vtt`（路径由调用方经 `final_stem` 契约传入，本函数不拼名）；原子写复用 `fs_utils._atomic_write_text`（`fs_utils.py:24`）；UTF-8 无 BOM；formats 空→no-op 返回 []。
2. **`subtransjav/refine/config.py`**（`RefineConfig` dataclass，:271 起）：新增字段 `extra_output_formats: list = field(default_factory=list)`（放 `output_dir` 附近）。
3. **`subtransjav/refine/cli.py`**：argparse 新增 `--extra-output-format`（`choices=["ass","vtt"]`、`action="append"`、`default=[]`）；`config_from_args`（:337 起）组装处透传 `extra_output_formats=args.extra_output_format`。
4. **`subtransjav/refine/pipeline_v2.py`**：终稿落盘段（:1604-1607，锚 `emitter.emit("phase_started", phase="final"` 与 `_atomic_write_text(out_final_path, build_srt(final_entries))`）之后追加 `sync_extra_outputs(out_final_path, final_entries, sorted(set(cfg.extra_output_formats) | set(existing_extra_formats(out_final_path))))`。:1265 复用跳过分支**不**追加（不凭空新增）。
5. **`subtransjav/refine/action_retranslate.py`**：终稿写回（:556-558，锚 `if applied_positions:` + `_atomic_write_text(str(final_path), new_srt)`）之后追加同款调用（cfg 旗标 ∪ existing；`run_action_retranslate(cfg, args)` :364 签名已有 cfg）。
6. **`subtransjav/refine/v2_outputs.py`**：备份表（:225-229 元组）追加 `f"_final_{final_suffix()}.ass"`、`f"_final_{final_suffix()}.vtt"` 两行（照 `.srt` 行既有模式，非 zh 方向不备份=既有 quirk 不修，D2026-1023-02 C7 裁定）；docstring（:211-219）同步列举；命名契约注释（:190-193）补一句「附加成品件名=final_stem+扩展，全仓只许经此取」。

## 先红后绿回归测试

- **新建 `tests/test_output_formats.py`**（先写红）：
  1. 多行文本 entries → ASS 回读逐条文本等于原文（`\N` 往返），文件内无裸换行截断 Dialogue 行；
  2. ASS timing 与源 ms 差 ≤10ms（centisecond 舍入口径）；VTT timing 逐 ms 相等；
  3. text 含 `{\i1}x{\i}` → 两格式输出均无 `\{\\`；
  4. text 含 `&`/`<b>` → VTT 原文断言含 `&amp;`/`&lt;`（**不以 pysubs2 自回读为唯一验证**，直接断言文件文本）；
  5. 零时长 entry → 输出 end>start；
  6. ASS 样式段快照断言：含 `Fontname=Microsoft YaHei`、`PlayResX: 1920`、`PlayResY: 1080`、不含 `Arial`；
  7. `sync_extra_outputs(formats=())` → 零落盘；
  8. `existing_extra_formats` 探测正确性。
- **`tests/test_pipeline_v2.py`**：新增 e2e 用例——cfg `extra_output_formats=["ass","vtt"]` 跑通后 `{stem}_final_cn.ass/.vtt` 在场、event 数=终稿 SRT 条数；既有默认用例补断言「无 `.ass/.vtt` 出现」（默认零变化钉）。
- **`tests/test_action_retranslate.py`**：新增用例——预置同名 `.ass` 附加件，重翻 apply 后 `.ass` 与终稿 SRT 逐条一致（再生非新增：无预置件时重翻后仍无 `.ass`）。
- 基线只增不减：现 2521+4，收口时全量 ≥2521+4+N，如实报数。
