## 改法

### 1. index.html——两钮换单钮

删除现有 `.aside-collapse-btn` 与 `.aside-expand-btn` 两钮，原位换**单钮**（零 id、零 data-i18n、零静态中文，aria-label/title 空值占位由 JS 回填）：

```html
<button type="button" class="aside-toggle-btn" data-testid="aside-toggle-btn" aria-label="" title="">
    <svg class="toggle-ic-collapse" viewBox="0 0 24 24" width="14" height="14" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="m6 9 6 6 6-6"/><path d="m6 15 6 6 6-6" opacity="0"/><path d="M4 4h16" opacity="0"/></svg>
    <svg class="toggle-ic-expand" viewBox="0 0 24 24" width="14" height="14" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="m6 15 6-6 6 6"/><path d="m6 9 6 6 6-6" opacity="0"/><path d="M4 20h16" opacity="0"/></svg>
</button>
```

图标用 Lucide `chevrons-right`（展开态显示=点击向右折叠）与 `chevrons-left`（折叠态显示=点击向左展开）双 path 画法（照 :93 内联先例；上为简化骨架，实现按 Lucide 官方 chevrons-right/chevrons-left 完整 path 落）。

### 2. style.css——双态形态

删旧两钮全部规则（共规块/hover/absolute/折叠态反转四段），换：

```css
/* 双功能把手（卡N）：展开态=右缘贴边竖条，折叠态=整条把手 */
.aside-toggle-btn {
    position: absolute;
    top: 0; right: 0; bottom: 0;
    width: 14px;
    padding: 0;
    border: none;
    border-radius: 0;
    background: transparent;
    color: var(--text-3);
    cursor: pointer;
    display: inline-flex;
    align-items: center;
    justify-content: center;
    transition: background var(--dur) ease, color var(--dur) ease;
}
.aside-toggle-btn:hover { background: var(--surface-2); color: var(--text-1); }
.aside-toggle-btn:focus-visible { outline: var(--focus-outline); outline-offset: -2px; }
.aside-toggle-btn .toggle-ic-expand { display: none; }

/* 折叠态：整条把手即按钮（件2 甲案落地） */
.workbench.aside-collapsed .aside { padding: 0; }
.workbench.aside-collapsed .aside-toggle-btn {
    position: static;
    width: 100%;
    flex: 1 1 auto;
    height: auto;
    align-self: stretch;
}
.workbench.aside-collapsed .aside-toggle-btn .toggle-ic-collapse { display: none; }
.workbench.aside-collapsed .aside-toggle-btn .toggle-ic-expand { display: inline-flex; }
```

同时删旧 `.workbench.aside-collapsed .aside` 组规则中的 `align-items/justify-content: center`（单钮满条不需居中栈）与 `padding: var(--space-2) 0`（由 `padding: 0` 覆盖，热区顶到条边）。
