
   （保留 `order: 99`——钉 :1004 正则逐字断言；同行化=去掉整行强制后自然流入第一行尾；420px+ellipsis 防长文本撑乱；`align-self:center` 与下拉框垂直平行。）
2. **app.js——R1' 简化**：新增 helper（`aiRefreshEffective` 附近，:7099 区）：
   ```js
   function shortenModelName(model) {
       // 卡R2（D2026-1013-01）：模型名展示简化——去 provider 前缀后前 12+…+后 8（全长>24 才简化）
       let s = String(model || '');
       const slash = s.indexOf('/');
       if (slash !== -1 && slash < 12) s = s.slice(slash + 1);
       if (s.length > 24) s = s.slice(0, 12) + '…' + s.slice(-8);
       return s;
   }
   ```
   `aiEffectiveLine` 模板（app.js:812）的 model 参数改为传 `shortenModelName(res.model)`（或模板内调用——实现位置执行者裁量，语义=显示名简化）；**`title` 全量**：`#refineAiPrivacy` 设置 `title = 完整未简化行文本`（悬停可读全名，无障碍等价）。
