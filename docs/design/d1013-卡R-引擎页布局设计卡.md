## owner 原始反馈（痛点转写，设计输入）

**反馈1（图一=引擎页「API 与模型选择」页全景截图）**：「折叠后 UI 整体布局不合理，比如部分框过长，整体视觉效果较差」。具体可指认：
- **阶段A/阶段B 卡**：两卡同构（开关+服务下拉+模型下拉+刷新+测试+API Key 行+地址行）。地址行=「阶段A 地址」label+超长输入框+「保存接口」蓝钮独占一整行——**框过长**的典型；API Key 行在模型行右端（刚修过收窄）。
- **兜底与容错卡**：三列排布（兜底槽位下拉/上下文窗口下拉+「净语配置目录」label+超长输入框（placeholder「留空=自动查找 (config/templates—包内默认)」占满整行）+浏览/打开钮）——**目录框过长**、三列与整行框混排视觉杂。
- **兜底与并发卡**：一行塞 5 控件（接管模型下拉+刷新圆钮+「云端故障时本地接管」开关+「批量 本地」数字框+「批量 云端」数字框），「并行」下拉独占第二行——**拥挤+错落**。
- owner 总评：整体视觉效果较差，需要布局级调整（不是单点修）。

**反馈2（图二=引擎页 AI 分析参数区局部）**：「跨片窗口框可以缩短，分析模型整体文字上移和框平行，如果文字过长导致错位可以调整简化分析模型文字描述」。现状：
- 「跨片窗口」下拉框（aggregateWindowSel）宽框但内容仅「30 天」等短选项——**框宽远超内容**；
- 下拉框下方一行 muted 文字「分析模型: 独立配置 — lmstudio/qwen3.6-35b-a3b-uncensored-heretic-apex」（模型状态回显行）——owner 要它**上移与框平行**（同行排布），文字过长错位则**简化文字**（如截断模型名/省略中段）。
