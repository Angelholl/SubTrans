# d1015 残余批 · 卡J · P2-9 右栏状态点五态接线（warn/ok/err 激活 CSS 死样式）+ 钉

> 以下命令均在项目根目录执行。规格依据：docs/design/d1015-P2残余批-设计规格.md §2（裁定追记 v2 R11 四条硬修订**全部纳入**）。**卡面行号参考，执行以 re-grep 定位；只动 app.js 前端态判定，桥层/后端零触碰。**

## 根因

`setDot`（ProgressManager 上，re-grep `setDot`）只切 dot-running/dot-idle 两态；CSS 五态类齐备（.dot-ok/.dot-warn/.dot-err 在 style.css 在位，ASR 页已在用）但右栏运行点永不变红/绿/琥珀——owner 主诉"出错也不变红"。
**⚠评议实测勘误（必须遵守）**：`startStatusPolling` 与 `_finish` 挂在 TranslatorManager 上，TranslatorManager **没有** setDot 方法（只有 setProgress/setStatus 转发）——**新调用点严禁想当然写 `this.setDot(...)`**；先读现有 3+1 处调用点（running/idle 各处，re-grep `setDot(`）的真实引用形态（可能经 ProgressManager 引用或事件），新调用照抄同款形态。

## 改动文件（仅 2 个）

1. `subtransjav/webview_gui/assets/app.js`
2. `tests/test_gui_js_static.py`

## 改法

**setDot 全集化**（ProgressManager 内原地改）：五类映射 `{idle:'dot-idle', running:'dot-running', ok:'dot-ok', warn:'dot-warn', err:'dot-err'}`，未知值回落 dot-idle；对五类做全量 toggle（当前类 true 其余 false）。

**_finish 增第二参**：`_finish(statusText, dotState = 'idle')`，收尾按上述真实引用形态 `setDot(dotState)`（不再硬编码 idle）。

**调用点接线**（re-grep 核位后落）：
- 轮询 tick 内风险降级：`risk_count > 0` 处（现仅拼状态文字后缀）加同形态 `setDot('warn')`（幂等，重复调用无副作用）；
- completed 正常完成：`warning_level` 为空 → `'ok'`；**`untranslated_majority` 完成分支（有告警框那条）归 'warn'**（防"绿点+告警框"矛盾）；`warning_level` ∈ {critical, warning} → `'warn'`；
- **error 三处全接**：collectOptions 的 catch `_finish(MSG.error…)`、start 主 catch、轮询 `status.status === 'error'` 分支——三处全传 `'err'`（re-grep `_finish(` 找全，勿漏）；
- cancelled 与 needs_confirm 取消：维持 `'idle'`（用户主动取消≠失败）；
- `reset()` 处调用点维持现状；
- 终态色（ok/warn/err）保留至下一次 start（start 的 setDot('running') 自然覆盖），不自动回灰。

**硬边界**：零新 CSS（dot-warn 无光环是既有设计）、零新 MSG 键、零桥层改动；心跳陈旧不转琥珀（登记不修）。

**钉**：tests 新增 `test_p29_status_dot_wired`：
- ① setDot 函数体含 `dot-ok`、`dot-warn`、`dot-err` 且含五类全集 toggle；
- ② `_finish` 函数体含第二参 `dotState` 并按其调 setDot；
- ③ 轮询函数体与 error 路径含 `'err'` 与 `'warn'` 分支——**断言须带真实引用前缀形态**（按 re-grep 到的形态写正则，禁裸 `setDot('err')` 子串断言防假绿）；
- ④ style.css `.dot-err` 规则仍在。
