## 根因

C22 现有流程要求 owner 手工操作 manifest json、播放器 seek、复标抽样与一致率统计，对非技术 owner 过重，且标注中间态无落盘保障。需要一个零第三方依赖的本地小工具，把 140 段标注变成「播放 → 点按钮 → 自动下一条」的问卷式体验，并自动完成复标抽样、一致率计算、回放 manifest 产出与一键回放启动器。

## 改法（功能规格）

### 子命令

- `--prepare --package <dir>`：读 `<dir>/c22_manifest.json`（**实测格式**：对象含 `_说明/generated_at/sample_count/labeled/samples[]`，samples 每条 = `{id, run, source, guide_path, media_path, timing, message, label:null}`，**已是逐间隙粒度**，如 `id="run1-29"`）。对每条 sample（保持数组序）：
  - 在位校验：guide_path / media_path 必须存在，缺失者汇总进中文报错后退出码 1；
  - ffmpeg 切片：`subtransjav.refine.asr_env.resolve_ffmpeg()` 定位；参数 `-y -ss <max(0,起-3)> -t <min(止-起+6,20)> -i <media_path> -vn -ac 1 -ar 16000 <dir>/clips/<id>.wav`（-ss 前置快 seek；subprocess 带 CREATE_NO_WINDOW / capture_output / timeout；ffmpeg 缺失 → 中文报错退出码 1）；
  - 原子写 `<dir>/state.json`：`records=[{id, run, wav, media, guide, timing, label:null, relabel:null}]`；
  - 写 `<dir>/开始标注.bat`：绝对路径 `.venv\Scripts\python.exe` + 本脚本 `--serve --package <dir>`，结尾 `pause`；
  - 完成打印中文摘要（N 段、涉及 run 与文件数、下一步指引）。
- `--serve --package <dir>`：http.server **只绑 127.0.0.1**，端口 8765 被占则 +1 重试至 8774；启动后 `webbrowser.open` 自动开页。路由：
  - `GET /` → 内嵌单页 HTML（全中文、零外部资源、按钮高 ≥44px、大字号、顶部常显「第 X / N 条 · 已标 Y · 待定 Z」进度）；
  - `GET /api/state` → state.json；`GET /clips/<id>.wav` → 本地片段文件；
  - `POST /api/answer` `{id, round:"first"|"re", value:"yes"|"no"|"skip"}` → 更新 state.json 并**每次点击即原子落盘**（断电不丢）；
  - `POST /api/relabel/start` → 从首轮已决条目随机抽 `ceil(20%)` 条进复标队列；
  - `GET /api/agreement` → `{total, agree, pct, disputed:[id…]}`（复标轮只认 yes/no，无 skip）。
  - UI 流：首轮=每条「▶ 播放（默认循环）/ 重听」+ 三大按钮「✅ 有对话」「❌ 无对话」「⏭ 稍后再听」，作答自动跳下一条、可回退改判；首轮无 pending → 显「进入复标（建议隔 1-2 天）」；复标轮**不回显**首轮答案；完成后即显一致率：≥90% 绿提示「可双击 一键回放.bat」，<90% 黄列争议条目支持重听改判（改判同步写回首轮 label）。
- `--merge --package <dir>`：首轮存在 pending（null 或 skip）→ 中文报错退出码 1 并报 pending 计数；否则按 `(guide, media)` 分组、保持 sample 原序，写 `<dir>/c22_manifest_labeled.json`：**harness 数组格式**，每组一条 `{guide:<guide_path>, media:<media_path>, timings:[该组 timing 序列], labels:[对齐 bool 数组]}`（走卡1 的 timings+labels 显式对齐口径——包内每文件只截取了「前 20 条」观测，导读全量条目可能更多，显式清单避免错位）；并写 `<dir>/一键回放.bat`（`.venv python tools\c22_calibration.py --manifest <标注包>\c22_manifest_labeled.json --out <标注包>\c22_report.md --enable` + `pause`；未达标时 harness 自拒写门=fail-closed，安全）。打印中文总结（true/false 分布、复标一致率、下一步）。

### 测试钉（tests/test_c22_labeler.py）

importlib 加载模块；ffmpeg 切片与 server 依赖注入/stub；server 用线程+urllib 真请求一轮：

- 钉1 prepare 解析实测包格式（dict+samples[]，2 run×2 sample → 4 records，id/顺序/wav 命名正确；媒体缺失 → 中文汇总报错退出码 1）；
- 钉2 切片参数（注入假 slicer 捕获参数：-ss clamp≥0、时长 cap 20s、-ac 1 -ar 16000）与 ffmpeg 缺失报错路径；
- 钉3 answer 原子落盘（os.replace 后无 .tmp 残留）与 skip→pending 语义；
- 钉4 merge：全决 → 按 (guide,media) 分组出 timings+labels 对齐数组 + 路径绝对；有 pending → 退出码 1；
- 钉5 复标一致率（28 条构 25 同 3 异 → 89.29% <90；26 同 → 92.86% ≥90）与争议 id 清单正确；
- 钉6 服务端仅绑 127.0.0.1（断言 server_address）。
