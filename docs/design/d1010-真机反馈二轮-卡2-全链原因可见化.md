## 改法

1. **去箭头**：`MSG.activity_stage_start`（app.js:710）`▶ ${stage} 开始` → `${stage} 开始`。
2. **digest 显示原因**（先 grep `fullchain_automation_status` 与「上次全链」digest 渲染点定位；前端已有读 last_run 的既有通道，纯 app.js 可达；若发现无通道即停卡说明）：
   - digest details 区（现显示「上次全链…」「复验三键计数差值…」处）追加逐文件 notices 渲染：`last_run.notices` 每条一行（最多 50 条；数组缺失/为空则整块不渲染）。
   - `phase=="skipped"` 且 `skip_reason` 非空 → 显示「未启动原因：{skip_reason}」（覆盖现固定文案 app.js:6951-6952 只说"服务商原因"不透值的缺口）。
   - `phase=="done"` 且 `entries_fixed==0` 且 notices 非空 → digest 顶部显示第一条 notices 作为原因行（防「看起来 done 但 0 修」无声）。
3. **口径说明行**（digest details 顶部固定一行，app.js 内联中文常量，零 data-i18n）：「全链仅自动修复白名单类目（且须有现译），可修数小于导读页"待修"数属正常」。
4. **原始日志未读徽标**（零 CSS 依赖，文本方案）：`ConsoleManager.log/appendRaw`（app.js:3221-3254）收行时若原始日志折叠（`#consoleOutput` display:none）→ 计未读数并更新 `rawLogToggleBtn` 文本为 `原始日志 •N`；展开时（`_initRawLogToggle` click 处理 app.js:3197-3201）清零还原 `MSG.raw_log_toggle` 现值。不改 strings.py。
