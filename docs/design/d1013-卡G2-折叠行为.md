## 改法（app.js）

1. **初始化（启动默认，照 theme :4506 try/catch 先例）**：
   ```js
   // 卡G2（D2026-1013-01）：aside 折叠启动默认——记忆优先，无记忆按窗口阈值
   let asideCollapsed = null;
   try { asideCollapsed = localStorage.getItem('subtransjav.aside.collapsed'); } catch (e) {}
   if (asideCollapsed !== '0' && asideCollapsed !== '1') {
       asideCollapsed = window.innerWidth <= 1240 ? '1' : '0';  // 无记忆：≤1240 默认收起
   }
   const workbenchEl = document.querySelector('.workbench');
   if (workbenchEl) workbenchEl.classList.toggle('aside-collapsed', asideCollapsed === '1');
   ```
