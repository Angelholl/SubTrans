## 批 1 —— S1 GUI 原生 alert/confirm/prompt 替换自制模态（候选池兑现）

- **背景**：原生对话框在 pywebview/WebView2 宿主存在支持差异风险（prompt 部分后端返回 null）——替换后行为宿主无关，兼具 polish 与防御性。黑盒实证边界：IAB 为 Chromium 非 WebView2，宿主结论不可达，故按防御性替换定性（CHANGELOG 中性措辞"改进"）。
- **替换面（5 处，grep 实证全集）**：app.js:540（ErrorHandler.show 的 alert）/:1273（window.confirm 覆盖终稿确认，async 上下文）/:1597（confirm F5 刷新警告——keydown 同步 handler 改 async）/:2060/:2062（glAdd 双 prompt）。
- **DOM**（index.html body 末尾、aboutModal 同层）：**全新 class-only 模式（库内无先例——aboutModal 实有内层 id aboutVersion（index.html:784），非先例；二级评议 Q1a 修正）**，复用 .modal-overlay 体系：
  ```html
  <div id="appModal" class="modal-overlay" style="display:none;" role="dialog" aria-modal="true">
      <div class="modal-card" data-testid="app-modal-card">
          <div class="modal-title" data-testid="app-modal-title"></div>
          <div class="modal-body" data-testid="app-modal-body"></div>
          <input type="text" class="form-input modal-input" style="display:none;" data-testid="app-modal-input">
          <div class="modal-actions">
              <button type="button" class="btn btn-ghost modal-cancel" data-testid="app-modal-cancel"></button>
              <button type="button" class="btn btn-primary modal-ok" data-testid="app-modal-ok"></button>
          </div>
      </div>
  </div>
  ```
  **新增 id 1 个**（appModal；data-testid 不匹配钉⑤ id 正则=0 预算，二级评议已逐字核验）；按钮文字 JS 填充 MSG.ui_ok/ui_cancel（静态键 +0）；**新增 modal 系 CSS 约 4 条规则**（.modal-card/.modal-title/.modal-actions/.modal-input——库内无既有规则，对齐 .modal-dialog 系 token style.css:1521-1568；二级评议 Q1a-3 修正：原"零新 CSS"声明不实）。
- **JS**：新增 AppModal 封装——`AppModal.alert(title, body)`/`AppModal.confirm(title, body) → Promise<boolean>`/`AppModal.prompt(title, body, def) → Promise<string|null>`；Esc/遮罩点击=取消；打开时 focus（input 或 ok 按钮）；**三项硬性条款（二级评议 Q3/Q4）**：①**打开中守卫**（busy 标志——async 模态不阻塞 JS，F5 连按/glAdd 双击会对单例二次 open 叠加，已打开则返回在途 Promise 或忽略新调用）；②**alert 形态隐藏取消键**；③AppModal 永不 reject（防 async handler unhandled rejection）；**:1597 F5 handler 改 async 时 `e.preventDefault()` 必须保持在首个 await 之前同步执行**（防 F5 默认刷新先跑——黑盒断言 confirm 挂起期间页面不刷新）。替换 5 处调用点（glAdd 改 async；:1597 handler 改 async）。ErrorHandler.show 非阻塞化语义安全（评议员全调用点实证：均为"展示后随即 _finish/return"模式，无阻塞依赖）；行为变化（错误模态打开期间 UI 可交互）CHANGELOG 中性措辞记账。
- **MSG 新增（JS 态，不入快照）**：ui_ok/ui_cancel（按钮文字）。替换点文案全部复用现有 MSG（overwriteConfirm/confirm_reload/gl_prompt_src/gl_prompt_dst 已在）。
