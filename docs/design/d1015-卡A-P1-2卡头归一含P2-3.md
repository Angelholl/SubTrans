## 改法（style.css，11 条）

目标②级卡头规格：`font-size: var(--font)` / `font-weight: 700` / `color: var(--text-2)` / 行布局 `display:flex; align-items:center; gap:var(--space-3)` / 分隔 `::after{content:""; flex:1; height:1px; background:var(--border)}`（尾 hairline）。写法先例=#pipelineCard .destination-section .section-header h2 的既有 ::after 块（re-grep `destination-section`）。

| # | 选择器（re-grep 锚） | 改动 |
|---|---|---|
| 1 | `.section-header h2` | 加 flex 行布局三声明 + `flex:1 1 auto; min-width:0;`；`var(--font-sm)`→`var(--font)`；`var(--text-1)`→`var(--text-2)`；新增 `h2::after` hairline（同 destination 先例写法） |
| 2 | `.section-header` 规则体 | **删 `border-bottom` 声明行**；padding 不动 |
| 3 | `.panel-card .section-header` 规则体 | **删 `border-bottom` 声明行**；padding 保留 |
| 4 | `.group-title`（基类） | 字级→`var(--font)`；600→700；加 flex+gap+`::after` hairline；色 text-2 不变 |
| 5 | `.adv-group > .group-title:first-child` | **删 padding-bottom 与 border-bottom**（下距由 .adv-group 自身 gap 承担，re-grep 确认该 gap=var(--space-2)） |

| 8 | `.form-card-header` | 600→700；`var(--text-1)`→`var(--text-2)`；`margin-bottom: var(--space-1)`→`var(--space-2)`；显式加 `font-size: var(--font);`；加 flex+gap+`::after` |
| 9 | `.block-title` | 600→700；`var(--text-1)`→`var(--text-2)`；加 flex+gap+`::after` hairline |
