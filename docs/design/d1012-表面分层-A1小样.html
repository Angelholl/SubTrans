对应审计报告 P0-1（三栏分层塌缩）与基线偏差裁定表 B-18（handoff §5「左栏浅灰 #F9FAFB」与 §6「中栏/右栏白色卡片」互相矛盾）。三档均不新增色值，只调整"哪个栏区用哪个 token"。

浅色实测（WCAG 相对亮度比）：现状 = 左栏 #F9FAFB / 中栏 #F3F4F6 / 右栏 #F3F4F6 → 左↔中 1.053:1、中↔右 1.000:1，三栏几乎不可分，分栏感只剩 1px 线（线与白卡 1.238:1）。
裁定要点：B-18 不是"现状 vs 基线"，而是 handoff 自身两处描述打架——§5/§105 写死左栏 #F9FAFB 与应用底 #F3F4F6，§6 又要"中栏主工作区白色卡片、右栏白色卡片"。在 1.05 的明度差下两者无法同时成立，必须选一个。
推荐档 ②：色值仍全部来自 handoff §5，只改层分配 → 栏间 1.108:1，工作区成为全屏唯一亮区。代价是中栏内卡片由白改浅灰，与 §6 字面有张力，须由 owner 在裁定表 B-18 勾选。
