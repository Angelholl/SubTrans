**c) 折叠态**：新类 `.workbench.aside-collapsed` → grid `220px minmax(0,1fr) 44px`；`.aside` 内卡全部隐藏，aside 变 44px 竖向把手条（居中竖排展开钮；**不放静态中文文案**——`test_html_has_no_unmarked_user_visible_chinese` 红线，纯图标+aria-label 最保守）。窄窗支路同步：`@media1180` 内 `.workbench.aside-collapsed { grid-template-columns: 64px minmax(0,1fr) 44px }`；**@media 内展态沿用既有 300px 规则不另立新规则（卡 G1 卡面写死，防实现者误加）**。与 `no-aside` 并存优先级：`no-aside` 更高（既有 :391 display:none 直接生效，校对页不渲染折叠交互，折叠类在该页不挂）。

**d) 窄屏默认收起 + 断点分工（618 教训落实）**：**owner 终审拍板（2026-10-13，D2026-1013-01）：启动默认阈值=1240**——JS `innerWidth <= 1240` → 默认收起；`> 1240` → 默认展开。**与 CSS 结构断点分轴不得混用**：`@media(max-width:1180px)`（style.css:2505-2506，rail 64px+aside 300px）仍是结构级窄栏断点；JS 轴=折叠启动默认、CSS 轴=窄栏结构，两判据独立各管各义。owner 理由：1181~1240 区间展开态主区仅 589~648px（较 618px 基准更窄，恰是 P1-7 要解决的最紧段），1240 下该区间默认收起主区约 861~920px，用户显式展开优先、记忆层兜底。**运行期语义（卡 G2 卡面写死）**：窗口阈值只作用启动默认，运行期不做 resize 自动切换（用户显式操作永久优先）。**分工声明**：结构级开合（要不要占位）用视口阈值定启动默认+用户显式操作优先；**内容级 reflow（badge/表单换行、表格列）一律容器基准**——后续用 `container-type: inline-size`（@container 作用于 .aside/.main 子孙）。pywebview 6.2.1 内核 Chromium 版本仍为审计 [INFO_GAP]①，file:// 走查实测定夺；不可用时回退 JS ResizeObserver 容器测宽。视口/容器两套判据的分工写死，防「断点基准须容器非视口」教训被误读成「启动默认也不许用视口宽」。

**e) 状态记忆落法（owner 终审拍板：localStorage 单写）**：先例两型——① theme：localStorage+后端 settings 双写（app.js:4506/4515）；② Console/词库折叠：无持久化（会话级，app.js:3268-3278 / 8008-8015）。aside 折叠属纯 UI 态、无后端消费 → **owner 拍板 localStorage 单写**（键 `subtransjav.aside.collapsed`，值 "1"/"0"）；不写后端 settings（不动 Api 契约）；无记忆值→按 d) 1240 窗口默认。**降级三分支（卡 G2 卡面写死，D2026-1013-01）**：a) 落地卡实测持久性 OK → 单写即定路线自然启用（无须再拍板）；b) 实测不持久 → 记忆层关闭、回落 1240 窗口默认；c) theme 式双写为**休眠备选**——启用必须经新的显式拍板，不得被降级链自动触发。**实测口径**：打包态 pywebview 重启与开发态 file:// 重启分别记（判定动作=写键→完全退出→重启→读回值在且折叠态恢复）；private/无痕 同降级（写入后读回为空即判不持久）。**已知代价**：应用升级/换数据目录可能清 localStorage → 记忆"似持久实则升级复位"（仅回落默认，非数据丢失），卡面记明防误报缺陷。
