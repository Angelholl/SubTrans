# d1016 卡D · 导读卡空态光秃标题收口（#guideJsonBlocks 初始隐藏）+ 钉

> 以下命令均在项目根目录执行。需求依据：owner 真机截图指认（2026-10-16，质量页空态下「结论/章节导读/行动条目/伴生文件」四行 h4 光秃显示）。**卡面行号参考，执行以 re-grep 定位。**

## 根因

`#guideJsonBlocks`（内含四个 h4 区块标题与四个内容容器，index.html re-grep 定位）在静态 HTML 中默认可见；空态（启动首屏/未加载导读）下容器全空 → 只剩四行光秃标题。而渲染链路本就管理显隐：`guideRender` 载入 json 导读时 `jsonBlocks.style.display = ''` 点亮（app.js re-grep，现 L6145-6146）、`guideRenderTxt` txt 模式隐藏（现 L6431）——唯一缺口=初始空态可见。

## 方案

`#guideJsonBlocks` 初始 `display:none`：空态四行标题消失（「暂无导读数据」提示行成为唯一内容，语义干净）；载入 json 导读后既有逻辑自动点亮；txt 模式既有逻辑保持隐藏。app.js 零改动。

## 改动文件（仅 2 个）

1. `subtransjav/webview_gui/assets/index.html`（仅 1 个 style 属性）
2. `tests/test_gui_js_static.py`

## 改法

### 1. index.html

`<div id="guideJsonBlocks">` → `<div id="guideJsonBlocks" style="display:none;">`。

零 id 增删、零 data-i18n 改动（FROZEN_IDS / ui_contract_snapshot 不动；仅补 1 个 style 属性）。

### 2. tests/test_gui_js_static.py（先红后绿）

新增 `test_guide_json_blocks_initial_hidden`：

- ① index.html 中 `id="guideJsonBlocks"` 所在标签含 `style="display:none;"`（正则断言）；
- ② app.js `guideRender` 含 `jsonBlocks.style.display = ''`（json 载入点亮既有行为，锁定防回潮）；
- ③ app.js `guideRenderTxt` 含 `jsonBlocks.style.display = 'none'`（txt 模式隐藏既有行为，锁定）；
- ④ index.html 四个 h4 的 data-i18n 键（guide_conclusions/guide_sections/guide_items_title/guide_companions）各出现次数恒为 1（防误动标题本体）。

流程：先写钉 → ① 必红 → 落 index.html 属性 → 全绿。红/绿输出原文贴执行记录。
