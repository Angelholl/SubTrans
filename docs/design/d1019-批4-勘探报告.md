## 五、加载期语义：唯一的前向引用命中

对 15 条非声明顶层语句做「引用是否已在更早语句/更早文件声明」判定，**唯一命中**：

```
L159  TranslatorManager.guideAutoDetect = guideAutoDetect;
L1701 function guideAutoDetect() { guideLoad(true); }
```

- 现状为何能跑：`guideAutoDetect` 是 **同一函数作用域** 内的函数声明，声明提升使其在 L159 已存在。
- 升顶层后为何会炸：函数声明只提升到**本脚本**顶部；L159 位于 `app-refine-core.js`，`guideAutoDetect` 位于
  `app-refine-guide.js`（后加载）→ 求值 L159 时全局不存在该绑定，抛 `ReferenceError`，**core 块余下语句全部不执行**。
- 消费方：`app-translator.js:362` `if (typeof this.guideAutoDetect === 'function') this.guideAutoDetect();`
  ——若赋值丢失，`typeof` 守卫会**静默跳过**翻译完成后的自动探测，无报错、无日志（静默功能退化）。

**处置（方案书轴2 采纳项）**：把 L159 整行搬到 `guideAutoDetect` 声明之后（L1703 之后），其余字节不动。
该行在任何运行期调用之前执行（所有调用点都在事件/异步链内），语义等价。

其余 14 条非声明语句的引用均可解析：`buildRefineOptions` 在 L104（同文件更早）、`DICT_KINDS` 在 L3601（同文件更早）、
`MSG`/`AppState`/`TranslatorManager`/`AppModal` 等来自**更早加载**的分文件；`bindDom` 在 L3202（更早）。
