## 改法

1. **index.html——三组包装**：兜底与并发卡 `.field-row` 内 5 label 按语义包 3 个 `.ctrl-group`（无 id 无 data-i18n 新增；组内元素原样）：
   - 组1 接管：`label`（接管模型下拉+刷新钮）
   - 组2 云端故障开关：`label`（「云端故障时本地接管」开关）
   - 组3 批量：`label`（批量本地+批量云端两数字框）
   「并行」下拉 label 保留 `.field-row` 直接子级（移出折行困境：组3 之后，或并入组3 尾——**按视觉自然并入组3**（批量与并行同属并发参数），执行者按 DOM 实况裁量，验收=不孤行）。
2. **style.css**：
   ```css
   .ctrl-group { display: flex; align-items: center; gap: var(--space-2); }
   .form-card .field-row { gap: var(--space-3); }   /* 16px 组间距（组内 8px 分级） */
   ```
   若「并行」并入组3 则无需额外规则；若保留独立则 `.field-row > label:last-child { margin-left: auto; }` 右锚（评议员「并行右锚」建议）。
3. **tests——两钉**：
   - **卡R3 移交固化** `test_fallback_card_layout`：按卡R3 卡面「先红后绿」段断言（fallback-card 类在位三子元素不变+乙案三规则在位）——结构已在位直接绿，红相已由卡R3 留证。
   - 新钉 `test_concurrency_card_groups`：断言 index.html 兜底与并发卡含 3 处 `.ctrl-group`、6 个既有 id 各恰 1 次、`refineConcurrency` 读取链不变（app.js 零改动的静态佐证）。
